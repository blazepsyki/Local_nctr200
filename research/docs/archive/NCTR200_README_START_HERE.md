# NCTR-200 WiFi 로컬 TCP 게이트웨이 — 새 세션 시작 안내

1. `NCTR200_WiFi_Local_Gateway_Handoff_2026-10-19.md`를 **최신 기준 문서**로 우선 읽는다.
2. `nctr_local_autoid_server_v4.py`가 최근 실기에서 작동한 TCP 서버 소스다. **이것은 실험용이며 상시 운영용이 아님**.
3. `references/`의 2026-10-15 문서는 초기 APK/PCAP 분석 기반이지만 최신 실기 확인 사항 일부(`0002` 등록 코드, `0102` 온도 다이얼, `0106` 외출 이벤트 등)를 포함하지 않는다. 상충하면 인수인계 최신 문서를 우선한다.
4. 첨부 대화/파일에서 실제 2026-10-18/19 로그를 검토한다. 보일러와 관련한 설정 변경은 물리 조절기에서 즉시 복구 가능할 때만 시험한다.
5. 이 ZIP에는 약 50MB PCAP과 64MB Logcat 등 대용량 원본 자료를 **포함하지 않았다**. 원시 패킷 분석이 필요하면 새 세션에 별도로 첨부한다.
6. 실제 `nodeId` 전체, Wi-Fi 암호, 로그인 정보 및 제조사 MQTT 비밀번호는 인수인계 문서에 넣지 않았다.
